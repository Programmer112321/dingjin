Downloading and Analyzing GEDI L4A Above-Ground Biomass Data

LiDAR
GEDI
Biomass

May 14, 2026

Overview

GEDI L4A (Global Ecosystem Dynamics Investigation, Level 4A) provides footprint-level estimates of above-ground biomass density (AGBD) in Mg/ha, derived from GEDI’s full-waveform LiDAR measurements. Each footprint is ~25 m in diameter, with ~60 m along-track spacing and ~600 m cross-track spacing.

This tutorial compares GEDI L4A AGBD across two contrasting landscapes:

Region Site Land Cover
Region 1 NEON SCBI — Front Royal, Virginia Temperate deciduous forest
Region 2 Central Park & surroundings — New York City Urban green space

Steps covered:

  1. Define two study areas
  2. Find and download GEDI L4A granules
  3. Read and extract AGBD from HDF5
  4. Quality filtering
  5. Spatial visualization for each region
  6. Side-by-side comparison

region_to_sf <- function(r) {
  st_bbox(c(xmin = r$lon_min, ymin = r$lat_min,
            xmax = r$lon_max, ymax = r$lat_max),
          crs = 4326) |> st_as_sfc() |> st_as_sf()
}

Step 2 — Find GEDI L4A Granules

library(httr)
library(jsonlite)

gedi_finder <- function(r) {
  url <- paste0(
    "https://lpdaacsvc.cr.usgs.gov/services/gedifinder",
    "?product=GEDI04_A",
    "&version=002",
    "&bbox=", r$lon_min, ",", r$lat_min, ",", r$lon_max, ",", r$lat_max
  )
  resp     <- GET(url)
  granules <- fromJSON(content(resp, "text"))$data
  return(granules)
}

scbi_granules <- gedi_finder(scbi)
nyc_granules  <- gedi_finder(nyc)

cat("SCBI granules:", length(scbi_granules), "\n")
cat("NYC  granules:", length(nyc_granules),  "\n")

Step 3 — Download Granules

Requires a free NASA EarthData account at urs.earthdata.nasa.gov.

library(rGEDI)

# Download SCBI granules
gediDownload(filepath = scbi_granules, outdir = "data/gedi_scbi")

# Download NYC granules
gediDownload(filepath = nyc_granules,  outdir = "data/gedi_nyc")

Tip: Each granule is ~500 MB–2 GB. For a small bounding box, usually 1–3 granules are sufficient.

Step 4 — Read and Extract AGBD from HDF5

A single reusable function handles both regions:

extract_gedi_l4a <- function(h5_path, region) {

  h5    <- H5File$new(h5_path, mode = "r")
  beams <- c("BEAM0000", "BEAM0001", "BEAM0010", "BEAM0011",
             "BEAM0101", "BEAM0110", "BEAM1000", "BEAM1011")

  results <- lapply(beams, function(beam) {
    if (!beam %in% names(h5)) return(NULL)
    tryCatch({
      b <- h5[[beam]]
      data.frame(
        lon        = b[["lon_lowestmode"]][],
        lat        = b[["lat_lowestmode"]][],
        agbd       = b[["agbd"]][],
        agbd_lower = b[["agbd_pi_lower"]][],
        agbd_upper = b[["agbd_pi_upper"]][],
        quality    = b[["l4_quality_flag"]][],
        degrade    = b[["degrade_flag"]][],
        beam       = beam
      )
    }, error = function(e) NULL)
  })

  h5$close_all()

  bind_rows(results) |>
    filter(lon >= region$lon_min, lon <= region$lon_max,
           lat >= region$lat_min, lat <= region$lat_max)
}

# Extract for SCBI
scbi_raw <- list.files("data/gedi_scbi", pattern = "\\.h5$", full.names = TRUE) |>
  lapply(extract_gedi_l4a, region = scbi) |> bind_rows()

# Extract for NYC
nyc_raw  <- list.files("data/gedi_nyc",  pattern = "\\.h5$", full.names = TRUE) |>
  lapply(extract_gedi_l4a, region = nyc)  |> bind_rows()

cat("SCBI raw footprints:", nrow(scbi_raw), "\n")
cat("NYC  raw footprints:", nrow(nyc_raw),  "\n")

Step 5 — Quality Filtering

quality_filter <- function(df) {
  df |> filter(quality == 1, degrade == 0, agbd >= 0, agbd < 1000)
}

scbi_clean <- quality_filter(scbi_raw)
nyc_clean  <- quality_filter(nyc_raw)

cat("SCBI after filtering:", nrow(scbi_clean), "shots\n")
cat("NYC  after filtering:", nrow(nyc_clean),  "shots\n")

Step 8 — Rasterize to 500 m Grid

rasterize_agbd <- function(df, region, res = 0.0045) {
  r_template <- rast(
    xmin = region$lon_min, xmax = region$lon_max,
    ymin = region$lat_min, ymax = region$lat_max,
    resolution = res, crs = "EPSG:4326"
  )
  vect(df, geom = c("lon", "lat"), crs = "EPSG:4326") |>
    rasterize(r_template, field = "agbd", fun = "mean")
}

r_scbi <- rasterize_agbd(scbi_clean, scbi)
r_nyc  <- rasterize_agbd(nyc_clean,  nyc)

par(mfrow = c(1, 2))
plot(r_scbi, col = hcl.colors(100, "YlGn"),

plot(r_nyc,  col = hcl.colors(100, "YlGn"),

Key Notes

  • Coordinate system: All GEDI L4A coordinates are WGS84 (EPSG:4326).
  • AGBD fill value: Shots with agbd = -9999 are no-data — always filter before analysis.
  • Prediction interval: agbd_pi_lower / agbd_pi_upper give the 90% prediction interval per footprint.
  • Power vs coverage beams: Power beams (BEAM0101, BEAM0110, BEAM1000, BEAM1011) yield higher-quality waveforms in dense canopy.
  • Urban interpretation: GEDI AGBD in urban areas reflects trees in parks, street trees, and green rooftops — not building biomass. Low AGBD pixels in NYC correspond to impervious surfaces where GEDI detected no canopy.
  • Version: Always use V002 — it includes updated allometric models and expanded geographic coverage.
