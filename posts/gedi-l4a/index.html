Downloading and Analyzing GEDI L4A Above-Ground Biomass Data

LiDAR
GEDI
Biomass
R

May 14, 2026

Overview

GEDI L4A (Global Ecosystem Dynamics Investigation, Level 4A) provides footprint-level estimates of above-ground biomass density (AGBD) in Mg/ha, derived from GEDI’s full-waveform LiDAR measurements. Each footprint is ~25 m in diameter, with ~60 m along-track spacing and ~600 m cross-track spacing.

This tutorial walks through:

  1. Defining a small study area
  2. Finding and downloading GEDI L4A granules
  3. Reading and extracting AGBD data from HDF5 files
  4. Applying quality filters
  5. Visualizing results spatially

Step 2 — Find GEDI L4A Granules

Use the GEDI Finder API to identify granules intersecting your bounding box.

library(httr)
library(jsonlite)

# GEDI Finder API — returns granule URLs for L4A
gedi_finder <- function(lon_min, lat_min, lon_max, lat_max) {
  url <- paste0(
    "https://lpdaacsvc.cr.usgs.gov/services/gedifinder",
    "?product=GEDI04_A",
    "&version=002",
    "&bbox=", lon_min, ",", lat_min, ",", lon_max, ",", lat_max
  )
  resp <- GET(url)
  granules <- fromJSON(content(resp, "text"))$data
  return(granules)
}

granule_urls <- gedi_finder(lon_min, lat_min, lon_max, lat_max)
cat("Found", length(granule_urls), "granules\n")
head(granule_urls)

Step 4 — Read and Extract AGBD from HDF5

GEDI L4A files are in HDF5 format with 8 beam groups (BEAM0000 to BEAM0101). Each beam contains shot-level data.

# Path to a downloaded GEDI L4A granule
h5_file <- "data/gedi_l4a/GEDI04_A_2021155002011_O14006_04_T05639_02_002_02_V002.h5"

# Function to extract data from all beams in one granule
extract_gedi_l4a <- function(h5_path, bbox) {

  h5 <- H5File$new(h5_path, mode = "r")

  # GEDI L4A beam names
  beams <- c("BEAM0000", "BEAM0001", "BEAM0010", "BEAM0011",
             "BEAM0101", "BEAM0110", "BEAM1000", "BEAM1011")

  results <- lapply(beams, function(beam) {

    # Check beam exists
    if (!beam %in% names(h5)) return(NULL)

    tryCatch({
      b <- h5[[beam]]

      lat      <- b[["lat_lowestmode"]][]
      lon      <- b[["lon_lowestmode"]][]
      agbd     <- b[["agbd"]][]              # AGBD in Mg/ha
      agbd_pi  <- b[["agbd_pi_lower"]][]    # Lower 90% prediction interval
      agbd_piu <- b[["agbd_pi_upper"]][]    # Upper 90% prediction interval
      quality  <- b[["l4_quality_flag"]][]  # 1 = high quality
      degrade  <- b[["degrade_flag"]][]     # 0 = not degraded

      data.frame(
        lon      = lon,
        lat      = lat,
        agbd     = agbd,
        agbd_lower = agbd_pi,
        agbd_upper = agbd_piu,
        quality  = quality,
        degrade  = degrade,
        beam     = beam
      )
    }, error = function(e) NULL)
  })

  h5$close_all()

  # Combine all beams
  df <- bind_rows(results)

  # Spatial filter to bounding box
  df <- df |>
    filter(lon >= bbox[1], lon <= bbox[3],
           lat >= bbox[2], lat <= bbox[4])

  return(df)
}

# Extract from all downloaded granules
h5_files <- list.files("data/gedi_l4a", pattern = "\\.h5$", full.names = TRUE)

gedi_raw <- lapply(h5_files, extract_gedi_l4a, bbox = bbox) |> bind_rows()

cat("Total footprints in bounding box:", nrow(gedi_raw), "\n")

Step 5 — Quality Filtering

GEDI L4A includes two key quality flags:

Flag Values Meaning
l4_quality_flag 1 = high quality Reliable AGBD estimate
degrade_flag 0 = not degraded Acquired during nominal ops 
gedi_clean <- gedi_raw |>
  filter(
    quality == 1,     # High-quality shots only
    degrade == 0,     # No degraded acquisitions
    agbd >= 0,        # Remove fill values
    agbd < 1000       # Remove unrealistic outliers
  )

cat("Footprints after quality filtering:", nrow(gedi_clean), "\n")
cat("Removed:", nrow(gedi_raw) - nrow(gedi_clean), "shots\n")

Step 8 — Rasterize AGBD

Convert footprint-level AGBD to a gridded raster at 500 m resolution for area-level summaries.

library(terra)

# Create empty raster template at 500 m (~0.0045 deg)
r_template <- rast(
  xmin = lon_min, xmax = lon_max,
  ymin = lat_min, ymax = lat_max,
  resolution = 0.0045,
  crs = "EPSG:4326"
)

# Convert to SpatVector
gedi_vect <- vect(gedi_clean, geom = c("lon", "lat"), crs = "EPSG:4326")

# Rasterize — mean AGBD per cell
r_agbd <- rasterize(gedi_vect, r_template, field = "agbd", fun = "mean")

# Plot
plot(r_agbd,
     col     = hcl.colors(100, "YlGn", rev = FALSE),
     main    = "Mean AGBD per 500 m cell (Mg/ha)",
     legend  = TRUE)

Step 9 — Summary Statistics by Subregion

# Summarize by 0.1° grid cells
gedi_summary <- gedi_clean |>
  mutate(
    lon_bin = round(lon / 0.1) * 0.1,
    lat_bin = round(lat / 0.1) * 0.1
  ) |>
  group_by(lon_bin, lat_bin) |>
  summarise(
    mean_agbd   = mean(agbd, na.rm = TRUE),
    median_agbd = median(agbd, na.rm = TRUE),
    sd_agbd     = sd(agbd, na.rm = TRUE),
    n_shots     = n(),
    .groups = "drop"
  )

print(gedi_summary)

Key Notes

  • Coordinate system: All GEDI L4A coordinates are in WGS84 (EPSG:4326).
  • AGBD fill value: Shots with agbd = -9999 are no-data and must be removed.
  • Prediction interval: agbd_pi_lower / agbd_pi_upper provide the 90% prediction interval — useful for uncertainty quantification.
  • Beam type: Power beams (BEAM0101, BEAM0110, BEAM1000, BEAM1011) penetrate dense canopy better than coverage beams and generally yield higher-quality waveforms.
  • Version: Always use Version 2 (V002) — it includes the most recent algorithm improvements and a larger set of predictive models.
