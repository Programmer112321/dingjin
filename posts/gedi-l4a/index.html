Downloading and Analyzing GEDI L4A Above-Ground Biomass Data

Overview

GEDI L4A (Global Ecosystem Dynamics Investigation, Level 4A) provides footprint-level estimates of above-ground biomass density (AGBD) in Mg/ha derived from NASA’s full-waveform LiDAR aboard the ISS. Each footprint is ~25 m in diameter with ~60 m along-track and ~600 m cross-track spacing.

This tutorial compares GEDI L4A AGBD across two contrasting landscapes:

Region Site Land Cover
Region 1 NEON SCBI — Front Royal, Virginia Temperate deciduous forest
Region 2 Central Park & surroundings — New York City Urban green space

region_to_sf <- function(r) {
  st_bbox(c(xmin = r$lon_min, ymin = r$lat_min,
            xmax = r$lon_max, ymax = r$lat_max),
          crs = 4326) |> st_as_sfc() |> st_as_sf()
}

Step 2 — Find GEDI L4A Granules

library(httr); library(jsonlite)

gedi_finder <- function(r) {
  url  <- paste0("https://lpdaacsvc.cr.usgs.gov/services/gedifinder",
                 "?product=GEDI04_A&version=002",
                 "&bbox=", r$lon_min, ",", r$lat_min,
                 ",",      r$lon_max, ",", r$lat_max)
  fromJSON(content(GET(url), "text"))$data
}

scbi_granules <- gedi_finder(scbi)
nyc_granules  <- gedi_finder(nyc)

cat("SCBI granules:", length(scbi_granules), "\n")
cat("NYC  granules:", length(nyc_granules),  "\n")

Step 3 — Download Granules

Requires a free NASA EarthData account (urs.earthdata.nasa.gov).

library(rGEDI)
gediDownload(filepath = scbi_granules, outdir = "data/gedi_scbi")
gediDownload(filepath = nyc_granules,  outdir = "data/gedi_nyc")

Each granule is ~500 MB–2 GB. For a small bounding box, typically 1–3 granules suffice.

Step 4 — Read and Extract AGBD from HDF5

GEDI L4A files are HDF5 with 8 beam groups. This function loops all beams and clips to the bounding box:

extract_gedi_l4a <- function(h5_path, region) {
  h5    <- H5File$new(h5_path, mode = "r")
  beams <- c("BEAM0000","BEAM0001","BEAM0010","BEAM0011",
             "BEAM0101","BEAM0110","BEAM1000","BEAM1011")

  results <- lapply(beams, function(beam) {
    if (!beam %in% names(h5)) return(NULL)
    tryCatch({
      b <- h5[[beam]]
      data.frame(
        lon        = b[["lon_lowestmode"]][],
        lat        = b[["lat_lowestmode"]][],
        agbd       = b[["agbd"]][],
        agbd_lower = b[["agbd_pi_lower"]][],
        agbd_upper = b[["agbd_pi_upper"]][],
        quality    = b[["l4_quality_flag"]][],
        degrade    = b[["degrade_flag"]][],
        beam       = beam
      )
    }, error = function(e) NULL)
  })
  h5$close_all()

  bind_rows(results) |>
    filter(lon >= region$lon_min, lon <= region$lon_max,
           lat >= region$lat_min, lat <= region$lat_max)
}

scbi_raw <- list.files("data/gedi_scbi", "\\.h5$", full.names = TRUE) |>
  lapply(extract_gedi_l4a, region = scbi) |> bind_rows()

nyc_raw  <- list.files("data/gedi_nyc",  "\\.h5$", full.names = TRUE) |>
  lapply(extract_gedi_l4a, region = nyc)  |> bind_rows()

Step 5 — Quality Filtering

quality_filter <- function(df) {
  df |> filter(quality == 1, degrade == 0, agbd >= 0, agbd < 1000)
}

scbi_clean <- quality_filter(scbi_raw)
nyc_clean  <- quality_filter(nyc_raw)

Quality flags used:

Flag Keep value Meaning
l4_quality_flag 1 Reliable AGBD estimate
degrade_flag 0 Nominal acquisition (no data degradation)

Step 6 — Rasterize to 500 m Grid

rasterize_agbd <- function(df, region, res = 0.0045) {
  r_tmpl <- rast(xmin = region$lon_min, xmax = region$lon_max,
                 ymin = region$lat_min, ymax = region$lat_max,
                 resolution = res, crs = "EPSG:4326")
  vect(df, geom = c("lon", "lat"), crs = "EPSG:4326") |>
    rasterize(r_tmpl, field = "agbd", fun = "mean")
}

r_scbi <- rasterize_agbd(scbi_clean, scbi)
r_nyc  <- rasterize_agbd(nyc_clean,  nyc)

par(mfrow = c(1, 2))
plot(r_scbi, col = hcl.colors(100, "viridis"),
     main = "SCBI Mean AGBD (Mg/ha)", range = c(0, 400))
plot(r_nyc,  col = hcl.colors(100, "viridis"),
     main = "NYC Mean AGBD (Mg/ha)",  range = c(0, 200))
par(mfrow = c(1, 1))

Key Notes

  • AGBD fill value: Filter out agbd == -9999 before any analysis.
  • Prediction interval: agbd_pi_lower / agbd_pi_upper give per-footprint 90% uncertainty bounds.
  • Power beams: BEAM0101, BEAM0110, BEAM1000, BEAM1011 penetrate dense canopy better and yield higher-quality waveforms.
  • Urban interpretation: GEDI AGBD in cities reflects canopy trees only — not building structure. Near-zero AGBD in NYC corresponds to streets, rooftops, and parking lots.
  • Version: Always use V002 — it includes updated allometric models and improved algorithm.
