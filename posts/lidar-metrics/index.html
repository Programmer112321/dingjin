A comprehensive guide to computing LiDAR structural metrics in R using lidR — canopy height percentiles, complexity indices (Rumple, VCI, CRR), density profiles, and building-specific metrics for urban morphology analysis.

Following the pre-processing pipeline, this post covers the extraction of structural metrics from the cleaned, height-normalized point cloud. Metrics are computed using lidR::cloud_metrics() (plot or tile level) and lidR::pixel_metrics() (rasterised, grid level). All examples assume the Height attribute has been saved as described in Stage 3 of the pipeline.

library(lidR)
library(sf)
library(terra)

las <- readLAS("clean_normalized.laz", select = "xyzrncH")
# x, y, z (raw), r (ReturnNumber), n (NumberOfReturns),
# c (Classification), H (Height above ground)

Part 1 — Canopy Height Metrics

Height percentiles are the backbone of LiDAR-based AGB and canopy height modelling. They characterise the vertical distribution of the canopy from the ground upward.

1.1 Height Percentiles and Basic Statistics

height_metrics <- function(z) {
  p  <- c(10, 25, 50, 75, 90, 95, 99)
  hp <- as.list(quantile(z, p / 100))
  names(hp) <- paste0("H", p)
  c(
    hp,
    Hmean = mean(z),
    Hmax  = max(z),
    Hsd   = sd(z),
    Hcv   = sd(z) / mean(z),         # coefficient of variation
    Hskew = moments::skewness(z),     # skewness
    Hkurt = moments::kurtosis(z),     # kurtosis
    Hqm   = sqrt(mean(z^2))           # quadratic mean height
  )
}

# Apply at pixel level (20 × 20 m grid)
metrics_grid <- pixel_metrics(las, ~height_metrics(Height[Height > 2]), res = 20)
Metric Formula Ecological meaning
H50 50th percentile Median canopy height — robust central tendency
H75 75th percentile Upper canopy layer indicator
H95 / H99 95th / 99th percentile Dominant / emergent height; proxy for top-of-canopy
Hmean \(\bar{H}\) Mean canopy height — strongly correlated with AGB
Hsd \(\sigma_H\) Vertical spread — indicator of structural heterogeneity
Hcv \(\sigma_H / \bar{H}\) Scale-free variability — useful across biomes
Hskew \(\mu_3 / \sigma^3\) Positive skew = bottom-heavy profile (young/regrowth)
Hkurt \(\mu_4 / \sigma^4\) Peakedness of height distribution
Hqm \(\sqrt{\bar{H^2}}\) Quadratic mean — more sensitive to tall trees than Hmean
Tip

H99 vs Hmax: Hmax is the single tallest point and is highly susceptible to surviving noise; H99 is far more robust. Most published AGB models use H99 or H95 as the maximum height proxy.

1.2 Canopy Cover and Gap Fraction

cover_metrics <- function(z, threshold = 2) {
  n_total <- length(z)
  n_above <- sum(z >= threshold)
  list(
    CC      = n_above / n_total,                  # canopy cover (fraction)
    GF      = 1 - n_above / n_total,              # gap fraction
    CC_first = sum(z[ReturnNumber == 1] >= threshold) /
               sum(ReturnNumber == 1)              # first-return cover
  )
}

Canopy cover (CC) from LiDAR:

\[CC = \frac{n_{\text{returns} \geq h_t}}{n_{\text{total returns}}} \times 100\%\]

where \(h_t\) is the cover threshold (commonly 2 m to exclude understorey). Gap fraction (GF = 1 − CC) is directly related to Beer-Lambert light extinction and is used as a proxy for leaf area index:

\[\text{LAI} \approx -\frac{\ln(\text{GF})}{k}\]

where \(k \approx 0.5\) for spherically distributed foliage.

Part 2 — Vertical Density and Profile Metrics

2.1 Density by Height Stratum

density_profile <- function(z) {
  breaks <- c(0, 0.5, 2, 5, 10, 20, 30, Inf)
  labels <- c("G", "S0.5", "S2", "S5", "S10", "S20", "S30")
  strata <- cut(z[z >= 0], breaks = breaks, labels = labels, right = FALSE)
  tab    <- table(strata)
  prop   <- as.list(prop.table(tab))
  names(prop) <- paste0("D_", names(prop))
  prop
}

The relative return density in each height stratum characterises the vertical foliage profile. Key derived ratios:

Ratio Meaning
D_S10 + D_S20 + D_S30 Upper canopy dominance
D_G + D_S0.5 Ground / near-ground proportion (bare soil indicator)
D_S2 / D_S10 Understory-to-upper-canopy ratio

2.2 Canopy Layer Separation

layer_metrics <- function(z) {
  # proportion above commonly used layer thresholds
  list(
    P_above2  = mean(z >= 2),
    P_above10 = mean(z >= 10),
    P_above20 = mean(z >= 20),
    ratio_sub = mean(z >= 2 & z < 10) / max(mean(z >= 10), 1e-6)
  )
}

ratio_sub (sub-canopy to upper-canopy ratio) distinguishes single-layer even-aged stands (low ratio) from multi-layered old-growth or mixed forests (high ratio).

Part 3 — Structural Complexity Metrics

These metrics quantify how geometrically heterogeneous and structurally complex a canopy is — properties closely linked to biodiversity, microclimate buffering, and habitat quality.

3.1 Rumple Index (RI)

The Rumple Index measures canopy surface rugosity: the ratio of the 3D canopy surface area to its 2D projected ground area.

\[RI = \frac{A_{3D}}{A_{2D}}\]

\(A_{3D}\) is computed by triangulating the canopy surface (TIN from first returns); \(A_{2D}\) is the projected footprint area of those triangles onto the horizontal plane. A flat, uniform canopy has \(RI \approx 1\); a complex, multi-layered canopy with deep gaps and tall emergents has \(RI \gg 1\).

# lidR computes RI from a Canopy Height Model raster
chm <- rasterize_canopy(las, res = 1, algorithm = p2r(subcircle = 0.2))
ri  <- rumple_index(chm)

Interpretation:

RI value Canopy type
1.0–1.1 Flat agricultural / grassland
1.1–1.3 Young even-aged plantation
1.3–1.6 Mature mixed forest
> 1.6 Old-growth, multi-layered, high structural complexity

Ecological relevance: RI is one of the strongest single-metric predictors of bird species richness and above-ground carbon in temperate and tropical forests. It captures both horizontal canopy gaps and vertical height variation simultaneously.

Important

RI is resolution-sensitive: a 0.25 m CHM resolves fine-scale branch-level rugosity; a 5 m CHM smooths it out. Always report the CHM resolution alongside RI, and use consistent resolution when comparing across sites.

3.2 Canopy Relief Ratio (CRR)

\[CRR = \frac{\bar{H} - H_{\min}}{H_{\max} - H_{\min}}\]

CRR ranges from 0 to 1. Low CRR (< 0.4) indicates a bottom-heavy height distribution with most mass near the ground — typical of low-stature or open canopies. High CRR (> 0.6) indicates a top-heavy distribution with most returns concentrated in the upper canopy — typical of dense, tall closed forests.

crr_metric <- function(z) {
  z <- z[z >= 0]
  list(CRR = (mean(z) - min(z)) / (max(z) - min(z) + 1e-6))
}

CRR complements H50: two stands can have the same median height but very different vertical distributions. A stand with CRR = 0.3 and H50 = 15 m has most of its foliage low; one with CRR = 0.7 and H50 = 15 m has most foliage concentrated near the top.

3.3 Vertical Complexity Index (VCI) — Shannon Entropy

VCI quantifies vertical structural diversity using information entropy. Divide the height range into \(n\) equal strata; compute the proportion of returns \(p_i\) in each stratum:

\[VCI = -\sum_{i=1}^{n} p_i \ln(p_i)\]

Maximum entropy (uniform distribution across all strata) \(= \ln(n)\). Normalised VCI \(= VCI / \ln(n)\) ranges from 0 (all returns in one stratum) to 1 (perfectly uniform vertical distribution).

vci_metric <- function(z, n_strata = 10) {
  z     <- z[z >= 0 & z < 80]
  strat <- cut(z, breaks = seq(0, 80, length.out = n_strata + 1), include.lowest = TRUE)
  p     <- prop.table(table(strat))
  p     <- p[p > 0]
  vci   <- -sum(p * log(p))
  list(VCI = vci, VCI_norm = vci / log(n_strata))
}

VCI_norm near 0: single-layer stand (e.g., plantation). VCI_norm near 1: returns distributed across all layers (old-growth, mixed age).

3.4 Height Distribution Shape Metrics

shape_metrics <- function(z) {
  z <- z[z >= 0]
  list(
    Hskew    = moments::skewness(z),    # right-skew = dense understory
    Hkurt    = moments::kurtosis(z),    # high = concentration around one height
    Hbimod   = bimodality_coefficient(z), # > 0.555 suggests two-layer canopy
    Hrange   = diff(range(z))           # full height range
  )
}

# Bimodality coefficient: BC = (skewness^2 + 1) / (kurtosis + 3*(n-1)^2/((n-2)*(n-3)))
bimodality_coefficient <- function(x) {
  n <- length(x)
  (moments::skewness(x)^2 + 1) /
  (moments::kurtosis(x) + 3 * (n - 1)^2 / ((n - 2) * (n - 3)))
}

3.5 All Complexity Metrics Together

complexity_metrics <- function(z) {
  z <- z[z >= 0]
  chm_local <- rasterize_canopy(...) # within pixel
  c(
    list(RI  = rumple_index(chm_local)),
    crr_metric(z),
    vci_metric(z),
    shape_metrics(z)
  )
}

Summary table:

Metric Range What it captures
Rumple Index (RI) ≥ 1 3D canopy surface rugosity
CRR 0–1 Vertical centre of mass
VCI (normalised) 0–1 Shannon diversity of height strata
Hskew −∞ to +∞ Asymmetry of height distribution
Hkurt > 0 Peakedness (concentration) of distribution
Bimodality coefficient 0–1 Two-layer canopy presence (> 0.555)

Part 4 — Building-Specific Metrics

In urban environments, the same point cloud contains both vegetation and buildings. After semantic segmentation (Classification: Class 6 = building, Class 5 = high vegetation), building-specific metrics can be extracted from the non-ground, non-vegetation returns.

# Extract building points only
las_bld <- filter_poi(las, Classification == LASBUILDING)   # Class 6

4.1 Building Height Metrics

Building height is not simply Hmax — roof geometry, chimneys, and HVAC units create outliers. Robust estimators:

building_height_metrics <- function(z) {
  list(
    Bh_p95   = quantile(z, 0.95),   # robust maximum → eave / parapet height
    Bh_p99   = quantile(z, 0.99),   # tallest structural element
    Bh_range = diff(range(z)),       # full height span (multi-floor buildings)
    Bh_floor = quantile(z, 0.95) / 3 # estimated floor count (3 m per floor)
  )
}
Metric Interpretation
H95 (building) Eave or parapet height — most common published building height
H99 (building) Chimney, rooftop equipment, or top of gable
Height range Multi-storey span — useful for stepped or mixed-use buildings
Floor count \(\approx H_{95} / 3\) — rough estimate, varies by construction era

4.2 Roof Geometry and Complexity

roof_metrics <- function(x, y, z) {
  # Fit plane to roof returns (PCA-based)
  pts  <- cbind(x, y, z)
  cov  <- cov(pts)
  eig  <- eigen(cov)
  # Normal vector = eigenvector of smallest eigenvalue
  normal    <- eig$vectors[, 3]
  slope_deg <- acos(abs(normal[3])) * 180 / pi

  # Roof slope variability (SD of per-triangle slopes from TIN)
  tin_slopes <- compute_tin_slopes(x, y, z)   # custom helper

  list(
    roof_slope_mean = slope_deg,
    roof_slope_sd   = sd(tin_slopes),          # planarity: low SD = flat roof
    roof_roughness  = sd(z - mean(z)),          # height residuals from mean roof plane
    roof_pts_density = length(z) /
      as.numeric(st_area(st_convex_hull(         # pts per m² on roof
        st_sfc(st_multipoint(cbind(x, y))))))
  )
}
Metric Low value High value
roof_slope_mean Flat roof (commercial) Steep gable/hip (residential)
roof_slope_sd Simple planar roof Complex multi-facet roof
roof_roughness Smooth surface Rough / cluttered roof

4.3 Building Footprint and Volume

building_footprint_metrics <- function(x, y, z) {
  pts2d <- st_sfc(st_multipoint(cbind(x, y)))
  hull  <- st_convex_hull(pts2d)

  footprint_area  <- as.numeric(st_area(hull))
  perimeter       <- as.numeric(st_length(st_cast(hull, "MULTILINESTRING")))
  height_p95      <- quantile(z, 0.95)
  volume_approx   <- footprint_area * height_p95   # box approximation

  # Compactness: circle has compactness = 1; elongated shapes < 1
  compactness <- 4 * pi * footprint_area / perimeter^2

  list(
    footprint_m2  = footprint_area,
    perimeter_m   = perimeter,
    compactness   = compactness,
    volume_m3     = volume_approx,
    FAR           = volume_approx / footprint_area  # Floor Area Ratio proxy
  )
}

4.4 Sky View Factor (SVF) and Urban Canyon Geometry

SVF quantifies what fraction of the hemisphere above a street-level point is open sky — a critical driver of urban thermal environment and cooling by urban green space.

\[SVF = 1 - \frac{1}{2\pi} \int_0^{2\pi} \sin^2\left(\theta(\phi)\right) d\phi\]

where \(\theta(\phi)\) is the elevation angle to the tallest obstruction at azimuth \(\phi\).

# Approximate SVF from rasterised DSM and DTM
dsm <- rasterize_canopy(las, res = 1, algorithm = p2r())
dtm <- rasterize_terrain(las, res = 1, algorithm = knnidw())
ndsm <- dsm - dtm   # normalised DSM = height above ground

# SVF via horizon angle scanning (using svf package or SAGA GIS)
# library(svf)
# svf_raster <- svf(ndsm, radius = 50, directions = 36)

H/W Ratio (Height-to-Width): for urban canyons (street flanked by buildings):

\[H/W = \frac{H_{\text{building}}}{W_{\text{street}}}\]

H/W Urban canyon type Thermal effect
< 0.5 Open street Low trapping; better sky access
0.5–2.0 Moderate canyon Intermediate
> 2.0 Deep canyon High heat trapping; reduced SVF

4.5 Building-Level Metrics vs. Vegetation Metrics — Comparison

Metric Vegetation Buildings Key difference
H95 Top-of-canopy height Eave/parapet height Same formula; different semantic meaning
Rumple Index Canopy rugosity Roof complexity RI > 1.5 = complex canopy OR multi-facet roof
Vertical entropy (VCI) Foliage layering Floor distribution VCI useful for multi-storey detection
Cover fraction Canopy cover Building coverage ratio BCR = building footprint / plot area
Volume Stem + crown volume Gross building volume Building volume used for FAR estimation
Density profile Understory / canopy strata Per-floor point density Building has regular vertical clustering at ~3 m intervals
Important

A key challenge in urban LiDAR analysis is co-classification error: tall trees adjacent to buildings share similar height and point density statistics. Always segment by classification (Class 5 = vegetation, Class 6 = building) before computing class-specific metrics. If classification is absent, use segment_trees() combined with geometric regularity tests (low Hsd within a building footprint = flat roof; high RI = vegetation).

4.6 Full Urban Metrics Pipeline

urban_metrics <- function(las_tile) {
  # Separate by class
  las_veg <- filter_poi(las_tile, Classification %in% c(LASVEGETATION, LASHIGHVEGETATION))
  las_bld <- filter_poi(las_tile, Classification == LASBUILDING)

  veg_m <- cloud_metrics(las_veg, ~{
    z <- Height[Height >= 0]
    list(
      H95        = quantile(z, .95),
      Hmean      = mean(z),
      Hsd        = sd(z),
      CC         = mean(z >= 2),
      VCI        = vci_metric(z)$VCI_norm,
      CRR        = crr_metric(z)$CRR
    )
  })

  bld_m <- cloud_metrics(las_bld, ~{
    list(
      Bh_p95       = quantile(Z, .95),
      Bh_floor     = quantile(Z, .95) / 3,
      roof_slope   = roof_metrics(X, Y, Z)$roof_slope_mean,
      roof_rough   = roof_metrics(X, Y, Z)$roof_roughness,
      footprint    = building_footprint_metrics(X, Y, Z)$footprint_m2,
      volume       = building_footprint_metrics(X, Y, Z)$volume_m3,
      compactness  = building_footprint_metrics(X, Y, Z)$compactness
    )
  })

  list(vegetation = veg_m, buildings = bld_m)
}
