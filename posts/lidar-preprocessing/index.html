Pre-Processing Airborne LiDAR Data: lidR vs lasR vs Python

LiDAR Preprocess
A complete LiDAR pre-processing pipeline shown in parallel across lidR, lasR, and Python (PDAL / laspy+scipy) — with pros/cons for every stage and in-depth comparisons of decimation and noise-removal strategies.
Author

Dingjin Chu

Published

February 15, 2026

Airborne LiDAR point clouds are rarely analysis-ready out of the box. Raw tiles from 3DEP, NEON AOP, or proprietary acquisitions often carry noise, inconsistent densities across acquisition campaigns, and missing height normalization. This post documents a reproducible pipeline covering every stage from raw LAS/LAZ ingestion to a clean, normalized, decimated cloud — shown side by side in lidR, lasR, and Python.

Package Overview

lidR lasR Python
Processing model Loads tiles as R LAS objects Streaming C++ pipeline; tiles never enter R memory PDAL: JSON streaming pipeline; laspy + scipy: loads tile as numpy arrays
API style Function calls on LAS / LAScatalog Stage composition with +, run via exec() PDAL: JSON config dict; laspy: OOP + numpy
Speed Moderate (R loop + C++ algorithms) Fastest (fully multi-threaded C++) PDAL ≈ lasR; laspy + scipy moderate
Memory footprint One chunk in RAM Constant (streaming) PDAL streaming; laspy loads full tile
Interactivity Best — easy mid-pipeline inspection Poor — batch only Good in Jupyter; harder to inspect PDAL mid-pipeline
Ecosystem R tidyverse, terra, sf R only NumPy, scikit-learn, Open3D, PyTorch, GDAL
Best for Exploration, small–medium datasets Production, HPC, large catalogs ML integration, custom algorithms, cross-platform

Python note: PDAL (pip install pdal) is the pipeline-based option — analogous to lasR. laspy (pip install laspy[lazrs]) + scipy is the object-based option — analogous to lidR. The examples below show whichever fits each stage best, with PDAL preferred for the full pipeline.

Note

Before processing: run the Pre-Flight Quality Check to validate CRS consistency, point density, Z-range sanity, return structure, and classification state across the full catalog.

import CSF

def classify_ground_csf(las):
    """Return a boolean mask of ground points using CSF."""
    pts = np.column_stack([las.x, las.y, las.z])

    c = CSF.CSF()
    c.params.bSloopSmooth    = True
    c.params.cloth_resolution = 0.5
    c.params.class_threshold  = 0.5
    c.params.time_step        = 0.65

    c.setPointCloud(pts.tolist())
    ground_idx     = CSF.VecInt()
    non_ground_idx = CSF.VecInt()
    c.do_filtering(ground_idx, non_ground_idx)

    mask = np.zeros(len(las.x), dtype=bool)
    mask[list(ground_idx)] = True
    return mask   # True = ground

# Apply only if no Class 2 exists

    ground_mask = classify_ground_csf(las)
    las.classification[ground_mask] = 2

from scipy.spatial import cKDTree

def normalize_height(las, k=10, p=2):
    """Build kNN-IDW DTM from ground points and compute height above ground."""
    gnd = las.classification == 2
    gx, gy, gz = las.x[gnd], las.y[gnd], las.z[gnd]

    # k-NN inverse-distance weighted interpolation
    tree   = cKDTree(np.column_stack([gx, gy]))
    dists, idx = tree.query(np.column_stack([las.x, las.y]), k=k)
    dists  = np.where(dists == 0, 1e-10, dists)   # avoid division by zero
    w      = dists ** (-p)
    ground_elev = (w * gz[idx]).sum(axis=1) / w.sum(axis=1)

    height = las.z - ground_elev

    # Save as extra-bytes attribute (preserves raw Z unchanged)
    las.add_extra_dim(laspy.ExtraBytesParams(
        name="Height", type=np.float32,
        description="Height above ground (m)"))
    las.Height = height.astype(np.float32)

    # Filter artifacts
    keep = (las.Height > -0.5) & (las.Height < 80)
    return las[keep]

# ── PDAL equivalent (used in full pipeline) ───────────────────────

def sor_filter(las, k=15, m=3, use_height=True):
    """Statistical Outlier Removal on 3D point coordinates."""
    z_col = las.Height if (use_height and hasattr(las, "Height")) else las.z
    pts   = np.column_stack([las.x, las.y, z_col])

    tree  = cKDTree(pts)
    # Query k+1 (first result is the point itself, dist=0)
    dists, _ = tree.query(pts, k=k + 1)
    mean_dists = dists[:, 1:].mean(axis=1)   # exclude self

    mu, sigma = mean_dists.mean(), mean_dists.std()
    keep = mean_dists <= mu + m * sigma
    return las[keep]

las = sor_filter(las, k=15, m=3)

# ── PDAL equivalent ────────────────────────────────────────────────
sor_stage_pdal = {
    "type":       "filters.outlier",
    "method":     "statistical",
    "mean_k":     15,
    "multiplier": 3.0
}

def voxel_decimate(las, res=0.447):
    """Keep one random point per voxel cell."""
    coords   = np.column_stack([las.x, las.y, las.z])
    vox_idx  = np.floor(coords / res).astype(np.int64)

    # Encode 3D index as a single integer key
    key = (vox_idx[:, 0] * 1_000_000_007 +
           vox_idx[:, 1] * 7_001 +
           vox_idx[:, 2])
    _, first = np.unique(key, return_index=True)
    return las[np.sort(first)]

full_pipeline <- function(las) {
  # Stage 2: ground (if absent)
  if (!any(las@data$Classification == LASGROUND))
    las <- classify_ground(las, csf(sloop_smooth=TRUE, class_threshold=0.5,
                                    cloth_resolution=0.5))
  # Stage 3: normalize + preserve both Z and Height
  dtm <- rasterize_terrain(las, res=1, algorithm=knnidw(k=10, p=2))
  las <- normalize_height(las, dtm)
  las <- add_lasattribute(las, las@data$Z, "Height", "Height above ground (m)")
  las <- unnormalize_height(las)
  las <- filter_poi(las, Height > -0.5 & Height < 80)
  # Stage 4: SOR
  las <- classify_noise(las, sor(k=15, m=3))
  las <- filter_poi(las, Classification != LASNOISE)
  # Stage 5: voxel decimation
  las <- decimate_points(las, voxel(1/sqrt(5)))
  return(las)
}

catalog_apply(ctg, full_pipeline)

def make_pipeline(infile, outfile):
    return {
        "pipeline": [
            # Stage 1: read + class filter
            {"type": "readers.las",
             "filename": infile},
            {"type": "filters.range",

            {"type":   "filters.voxelgrid",
             "leaf_x": vox_res,
             "leaf_y": vox_res,
             "leaf_z": vox_res},

            # Write output

             "filename":   outfile,
             "extra_dims": "HeightAboveGround=float32"}

# Batch process all tiles

Important

When to choose which:

  • lidR — exploring a new dataset, tuning parameters on one tile, needing add_lasattribute() to co-preserve raw Z and normalised Height in the same file.
  • lasR — production runs over large catalogs (> 50 GB), HPC environments, time-critical workflows. Expect 5–10× speedup over lidR.
  • Python / PDAL — workflows that feed into ML pipelines (scikit-learn, PyTorch), cross-platform environments without R, or when combining LiDAR with other Python geospatial tools (GDAL, Shapely, GeoPandas).

Divides 3D space into cubic voxels; retains one random point per occupied voxel.

Strengths: 3D spatial uniformity; removes density gradients from scan-angle overlap; best for mixed 3DEP campaigns. Weaknesses: fine-scale vertical structure within a voxel may be lost; no direct pts/m² targeting.

# No direct PDAL equivalent — implement with numpy 2D grid
def homogenize_decimate(las, target_density=10, cell_res=5):
    xi = np.floor(las.x / cell_res).astype(int)
    yi = np.floor(las.y / cell_res).astype(int)
    keep = np.zeros(len(las.x), dtype=bool)
    cell_area = cell_res ** 2
    max_pts   = int(target_density * cell_area)
    for (cx, cy), idx in _group_by(xi, yi):
        chosen = np.random.choice(idx, min(len(idx), max_pts), replace=False)
        keep[chosen] = True
    return las[keep]

def _group_by(xi, yi):
    from itertools import groupby
    pairs = sorted(zip(zip(xi, yi), np.arange(len(xi))), key=lambda x: x[0])
    for key, group in groupby(pairs, key=lambda x: x[0]):
        yield key, [g[1] for g in group]

2D cells randomly thinned to density pts/m²; cells below target are left untouched.

Strengths: explicit pts/m² target; removes horizontal density gradients; preserves full vertical structure. Weaknesses: 3D vertical clustering can persist; Python implementation requires more code.

1.4 Highest / Lowest per Cell

# No native equivalent in lasR at present.
# numpy approach — preserves all LAS attributes
def highest_point(las, res=1.0):
    xi  = np.floor(las.x / res).astype(int)
    yi  = np.floor(las.y / res).astype(int)
    key = xi * 1_000_000_007 + yi
    order = np.lexsort((las.z, key))
    _, last_in_group = np.unique(key[order], return_index=True)
    return las[order[last_in_group]]

def lowest_point(las, res=1.0):
    xi  = np.floor(las.x / res).astype(int)
    yi  = np.floor(las.y / res).astype(int)
    key = xi * 1_000_000_007 + yi
    order = np.lexsort((-las.z, key))
    _, first_in_group = np.unique(key[order], return_index=True)
    return las[order[first_in_group]]

# laspy + scipy (full control, inspectable intermediate arrays)
from scipy.spatial import cKDTree
pts  = np.column_stack([las.x, las.y, las.z])
tree = cKDTree(pts)
d, _ = tree.query(pts, k=16)        # k+1 (includes self)
md   = d[:, 1:].mean(axis=1)        # mean distance to 15 neighbours
keep = md <= md.mean() + 3 * md.std()
las  = las[keep]

2.4 Isolation Forest (ML-Based)

  • lidR
  • lasR
  • Python
# Via reticulate only
library(reticulate)
sklearn <- import("sklearn.ensemble")
# Not available in lasR
# Native Python — no R bridge needed
from sklearn.ensemble import IsolationForest
import numpy as np

features = np.column_stack([
    las.x, las.y, las.z,
    las.intensity,
    las.return_number,
    las.number_of_returns
])

iforest = IsolationForest(contamination=0.01, n_estimators=100, random_state=42)
labels  = iforest.fit_predict(features)   # 1 = inlier, -1 = outlier
las     = las[labels == 1]

Multi-attribute (intensity + return structure) — catches noise invisible to geometry-only SOR. Python is the natural home for this algorithm; lidR requires a Python bridge and lasR does not support it.
