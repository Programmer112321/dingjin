Downloading and Analyzing GEDI L2A Relative Height Metrics

Overview

GEDI L2A (Global Ecosystem Dynamics Investigation, Level 2A) provides footprint-level relative height (RH) metrics derived from full-waveform LiDAR. Unlike L4A which estimates above-ground biomass density, L2A reports the vertical distribution of returned energy — directly measuring canopy height structure.

Metric Meaning
RH25 Height below which 25% of waveform energy is returned
RH50 Median canopy height
RH75 Height below which 75% of energy is returned
RH95 Upper canopy height (~95th percentile) — most used as canopy height estimate
RH98 Near-maximum canopy height
RH100 Maximum height of any return

This tutorial applies the same workflow as GEDI L4A to two contrasting landscapes:

Region Site Land Cover
Region 1 NEON SCBI — Front Royal, Virginia Temperate deciduous forest
Region 2 Central Park & surroundings — New York City Urban green space

Step 2 — Find GEDI L2A Granules

library(httr); library(jsonlite)

gedi_finder <- function(r, product = "GEDI02_A") {
  url  <- paste0("https://lpdaacsvc.cr.usgs.gov/services/gedifinder",
                 "?product=", product, "&version=002",
                 "&bbox=", r$lon_min, ",", r$lat_min,
                 ",",      r$lon_max, ",", r$lat_max)
  fromJSON(content(GET(url), "text"))$data
}

scbi_granules <- gedi_finder(scbi)
nyc_granules  <- gedi_finder(nyc)

cat("SCBI granules:", length(scbi_granules), "\n")
cat("NYC  granules:", length(nyc_granules),  "\n")

Step 3 — Download Granules

library(rGEDI)

Each L2A granule is ~300 MB–1 GB. For a small bounding box, 1–3 granules typically suffice.

Step 4 — Read and Extract RH Metrics from HDF5

GEDI L2A stores RH metrics as a 101-element array (rh[0]…rh[100]) per shot. Index 95 = RH95, index 50 = RH50, etc.

extract_gedi_l2a <- function(h5_path, region) {
  h5    <- H5File$new(h5_path, mode = "r")
  beams <- c("BEAM0000","BEAM0001","BEAM0010","BEAM0011",
             "BEAM0101","BEAM0110","BEAM1000","BEAM1011")

  results <- lapply(beams, function(beam) {
    if (!beam %in% names(h5)) return(NULL)
    tryCatch({
      b  <- h5[[beam]]
      rh <- b[["rh"]][]        # matrix: shots × 101

      data.frame(
        lon          = b[["lon_lowestmode"]][],
        lat          = b[["lat_lowestmode"]][],
        elev_ground  = b[["elev_lowestmode"]][],
        rh25         = rh[, 26],   # 0-indexed: col 26 = RH25
        rh50         = rh[, 51],
        rh75         = rh[, 76],
        rh95         = rh[, 96],
        rh98         = rh[, 99],
        rh100        = rh[, 101],
        quality_flag = b[["quality_flag"]][],
        degrade_flag = b[["degrade_flag"]][],
        beam         = beam
      )
    }, error = function(e) NULL)
  })

  h5$close_all()

  bind_rows(results) |>
    filter(lon >= region$lon_min, lon <= region$lon_max,
           lat >= region$lat_min, lat <= region$lat_max)
}

scbi_raw <- list.files("data/gedi_l2a_scbi", "\\.h5$", full.names = TRUE) |>
  lapply(extract_gedi_l2a, region = scbi) |> bind_rows()

nyc_raw  <- list.files("data/gedi_l2a_nyc",  "\\.h5$", full.names = TRUE) |>
  lapply(extract_gedi_l2a, region = nyc)  |> bind_rows()

Step 5 — Quality Filtering

quality_filter <- function(df) {
  df |> filter(quality_flag == 1, degrade_flag == 0,
               rh95 >= 0, rh95 < 100)
}

scbi_clean <- quality_filter(scbi_raw)
nyc_clean  <- quality_filter(nyc_raw)
Flag Keep value Meaning
quality_flag 1 Valid waveform decomposition
degrade_flag 0 Nominal acquisition

Results

Spatial Distribution of RH95

SCBI shows uniformly tall canopy (RH95 20–40 m) consistent with mature temperate forest. NYC reveals a sharp spatial contrast: the Central Park core reaches 15–25 m, while surrounding urban pixels drop to near zero where impervious surfaces dominate.

RH95 Frequency Distribution

SCBI follows a near-normal distribution centred around 28 m. NYC shows a strongly bimodal pattern — a large mode below 5 m (streets, rooftops) and a secondary peak around 15–25 m (park trees).

Relative Height Profile — RH25 to RH98

The RH profile reveals canopy vertical structure. SCBI’s wide spread from RH25 to RH95 indicates a multi-layered forest with understory. NYC’s RH values remain low across all percentiles outside the park, reflecting sparse or absent canopy.

Step 6 — Rasterize RH95 to 500 m Grid

rasterize_rh <- function(df, region, field = "rh95", res = 0.0045) {
  r_tmpl <- rast(xmin = region$lon_min, xmax = region$lon_max,
                 ymin = region$lat_min, ymax = region$lat_max,
                 resolution = res, crs = "EPSG:4326")
  vect(df, geom = c("lon", "lat"), crs = "EPSG:4326") |>
    rasterize(r_tmpl, field = field, fun = "mean")
}

r_scbi_rh95 <- rasterize_rh(scbi_clean, scbi)
r_nyc_rh95  <- rasterize_rh(nyc_clean,  nyc)

par(mfrow = c(1, 2))

Step 7 — Compare RH Metrics Across Sites

combined <- bind_rows(
  mutate(scbi_clean, region = "NEON SCBI"),
  mutate(nyc_clean,  region = "NYC Urban")
)

# Long format for multi-metric comparison
rh_long <- combined |>
  select(region, rh25, rh50, rh75, rh95, rh98) |>
  pivot_longer(cols = c(rh25, rh50, rh75, rh95, rh98),
               names_to = "metric", values_to = "height") |>
  mutate(metric = toupper(metric))

# Summary table
rh_long |>
  group_by(region, metric) |>
  summarise(mean = round(mean(height), 1),
            sd   = round(sd(height),   1), .groups = "drop") |>
  pivot_wider(names_from = metric,
              values_from = c(mean, sd))

Key Notes

  • RH95 as canopy height: RH95 is the most widely used canopy height proxy from GEDI L2A, more stable than RH100 which is sensitive to noise returns.
  • Coordinate system: WGS84 (EPSG:4326) for all coordinates.
  • RH array indexing: In the HDF5 file, rh is 0-indexed — rh[96] = RH95, rh[51] = RH50, etc.
  • Quality flag: L2A uses quality_flag (not l4_quality_flag as in L4A). Keep only shots where quality_flag == 1.
  • Urban canopy: Low RH values in urban areas do not mean no trees — they reflect the average canopy height including large fractions of impervious surface within the ~25 m footprint.
  • Version: Always use V002 for the most accurate waveform decomposition algorithm.
